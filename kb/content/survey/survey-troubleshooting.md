| پیام یا علامت | علت و راه‌حل |
|---|---|
| «اجازه موقعیت داده نشد» | مجوز موقعیت مرورگر را برای سایت فعال کنید و صفحه را تازه کنید |
| «زمان دریافت موقعیت تمام شد» / «موقعیت در دسترس نیست» | به فضای باز بروید؛ GPS دستگاه را روشن کنید |
| «موقعیت قدیمی است؛ اتصال گیرنده را بررسی کنید» | ارتباط با گیرنده قطع یا کند است؛ دوباره وصل کنید |
| «این مرورگر Web Serial ندارد» یا «Web Bluetooth ندارد» | از Chrome یا Edge استفاده کنید ([گیرنده خارجی](kb:survey-external-receiver)) |
| «اتصال گیرنده خارجی در پلن‌های پولی فعال است» | پلن شما گیرنده خارجی ندارد ([سهمیه](kb:survey-quota)) |
| «ارتباط سریال قطع شد» | کابل یا بلوتوث را بررسی و دوباره «اتصال» را بزنید |
| «ارتباط قطع شد؛ تلاش دوباره…» | اتصال NTRIP قطع شده و خودکار دوباره تلاش می‌کند؛ اینترنت را بررسی کنید |
| «اتصال به کستر برقرار نشد» | نشانی، پورت، کاربر، گذرواژه و Mountpoint را بررسی کنید ([NTRIP](kb:survey-ntrip-rtk)) |
| «فهرست دریافت نشد» | نشانی و اطلاعات ورود کستر را بررسی کنید |
| «سقف نقطه پلن پر شد» | [ارتقای پلن](kb:upgrade-plan) یا حذف نقاط اضافه |
| «… مورد ارسال نشد» | داده نامعتبر یا سقف پلن؛ نقاط سالم ارسال شده‌اند |
| ثبت نقطه غیرفعال است | گیرنده هنوز موقعیت نداده یا شما بیننده‌اید |
| نقشه آفلاین ذخیره نمی‌شود | ذخیره فقط با اینترنت ممکن است؛ محدوده را کوچک کنید |

## هنوز حل نشد؟

نام پروژه، مرورگر و مدل گیرنده را بنویسید و [تیکت پشتیبانی](kb:support-ticket) بزنید. گذرواژه کستر یا کلید API را در تیکت ننویسید.
