## کجا؟

جدول را باز کنید و تب **ستون‌ها** را بزنید (برای مالک و ویرایشگر). **افزودن ستون** و **تغییر نام جدول** بالای فهرست‌اند؛ کارهای هر ستون در منوی ⋯ کنار آن.

## کارها

| کار | توضیح |
|---|---|
| افزودن ستون | نام، نوع، مقدار پیش‌فرض، اجباری، یکتا و ایندکس. ستون **اجباری** روی جدولِ پر فقط با مقدار پیش‌فرض ساخته می‌شود. |
| تغییر نام ستون یا جدول | نقشه‌ها و لایه‌های منتشرشده با تغییر نام جدول خودکار به نام تازه وصل می‌مانند؛ ولی کدی که نام قدیمی را دارد باید عوض شود. |
| تغییر نوع | مقدارها از راه متن به نوع تازه تبدیل می‌شوند. اگر حتی یک مقدار نخواند، هیچ‌چیز عوض نمی‌شود. مقدار پیش‌فرض ستون برداشته می‌شود. |
| اجباری / اختیاری | اجباری کردن وقتی ممکن است که ستون هیچ سطر خالی نداشته باشد. |
| مقدار پیش‌فرض | مقدار ثابت؛ `@now` برای تاریخ و زمان و `@uuid` برای شناسه‌ی خودکار. خالی یعنی برداشتن پیش‌فرض. |
| ایندکس | روی یک یا چند ستون؛ برای ستون هندسه ایندکس مکانی ([GiST](kb:spatial-index-gist)). ایندکس یکتا روی داده‌ی تکراری ساخته نمی‌شود. |
| هندسه | نوع، بُعد و [SRID](kb:what-is-srid) ستون هندسه. «تبدیل» مختصات‌ها را به SRID تازه جابه‌جا می‌کند؛ «فقط برچسب» وقتی است که SRID از اول اشتباه ثبت شده و مختصات‌ها درست‌اند. |
| حذف ستون | ستون و داده‌اش برای همیشه پاک می‌شود. |

## چه چیزی امن‌تان می‌کند

- هر تغییر پیش از اجرا **SQL** را نشان می‌دهد («SQL که اجرا می‌شود»).
- اجرا **همه‌یاهیچ** است؛ اگر خطا بیاید جدول دست‌نخورده می‌ماند و دلیل به فارسی گفته می‌شود.
- **حذف ستون، تغییر نوع، تغییر هندسه و تغییر نام جدول** باید با نوشتن نام ستون یا جدول تأیید شوند. پیش از آن‌ها [بکاپ بگیرید](kb:backup-manual).
- اگر جدول در نقشه یا لایه‌ی منتشرشده استفاده شود، هشدار می‌بینید.

## محدودیت‌ها

- ستون کلید اصلی را نمی‌شود حذف کرد یا اختیاری کرد.
- بعد از هر تغییر ساختار، «بازگردانی آخرین ذخیره»‌ی [حالت ویرایش](kb:edit-table-data) برای آن جدول پاک می‌شود، چون ستون‌ها عوض شده‌اند.
- هر تغییر حداکثر ۱۲۰ ثانیه وقت دارد؛ برای جدول‌های خیلی بزرگ در ساعت کم‌کار از [کنسول SQL](kb:sql-console) استفاده کنید.
- نما (view) و جدول خارجی از این‌جا تغییر نمی‌کنند. تعریف ایندکس‌های پیشرفته (روی عبارت، جزئی) و قیدهای خارجی از کنسول SQL است.
