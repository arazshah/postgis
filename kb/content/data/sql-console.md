## ویژگی‌ها

- نتیجه تا **۵۰۰ ردیف** نمایش داده می‌شود؛ اگر بیشتر بود اعلام می‌شود که نتیجه کوتاه شده است.
- هر کوئری حد زمانی دارد (حدود ۲۰ ثانیه)؛ بیشتر از آن [متوقف می‌شود](kb:err-statement-timeout).
- حالت پیش‌فرض **فقط‌خواندنی** است تا خطای ناخواسته داده را خراب نکند. برای تغییر داده حالت نوشتن را روشن کنید.
- اگر ستون هندسه (geometry یا geography) برگردد، ردیف‌های نتیجه روی نقشه هم دیده می‌شوند.
- اگر پرس‌وجوی خواندنی خالی بود، دکمه «چرا خالی است؟» دلیل احتمالی و کوئری اصلاح‌شده را پیشنهاد می‌کند ([راهنما](kb:sql-persian-question)).
- در تب **پرسش فارسی** می‌توانید خواسته را فارسی بنویسید تا دستور SQL آن ساخته شود؛ [راهنمای پرسش فارسی در کنسول SQL](kb:sql-persian-question).

## کارهای کوچک مفید

```sql
SELECT count(*) FROM roads;
SELECT * FROM roads LIMIT 10;
```

نمونه‌های تحلیل مکانی: [نزدیک‌ترین عارضه‌ها](kb:sql-nearest-features)، [بافر](kb:sql-buffer).

!!! tip
    برای کار طولانی (ساخت جدول بزرگ، ورود حجیم) از ابزار دسکتاپ مثل [psql یا pgAdmin](kb:connect-psql-pgadmin) استفاده کنید.
