- فقط مالک می‌تواند حذف کند.
- **قبل از حذف** [بکاپ دستی](kb:backup-manual) را دانلود کنید.
- بعد از حذف، نام پایگاه داده برای استفاده مجدد آزاد می‌شود.
- لایه‌های منتشرشده و فایل‌های وابسته هم پاک می‌شوند.
- اگر فقط می‌خواهید فضا آزاد کنید، [حذف جدول](kb:drop-table) کافی است.
- حذف خودکار بعد از انقضا: [چرخه اعتبار](kb:expiry-lifecycle).
