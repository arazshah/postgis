## مراحل

1. صفحه پایگاه داده ← **تیم و کاربران** ← «کاربران پایگاه داده».
2. نام، توضیح و دسترسی (**فقط‌خواندنی** یا **خواندن و ویرایش داده**) را انتخاب کنید.
3. رمز را همان لحظه ذخیره کنید؛ فقط یک بار نمایش داده می‌شود ([چرا؟](kb:password-shown-once)). رشته اتصال هم داده می‌شود.

## کی به‌کار می‌آید؟

- برنامه وب که فقط می‌خواند ← کاربر فقط‌خواندنی؛ اگر لو رفت داده خراب نمی‌شود.
- هر همکار یا ابزار ← کاربر جدا؛ قطع دسترسی یکی روی بقیه اثر ندارد.

ظرفیت کاربران طبق پلن: {{plan_db_roles}}. تفاوت با [عضو تیم](kb:team-roles): عضو تیم با حساب سایت وارد می‌شود، کاربر پایگاه داده فقط اتصال مستقیم PostgreSQL است.
