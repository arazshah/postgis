1. صفحه پایگاه داده ← **تغییر رمز**.
2. رمز دلخواه ([قواعد](kb:password-rules)) یا رمز تصادفی را تأیید کنید.
3. رمز جدید را همان لحظه ذخیره کنید ([یک‌بار نمایش](kb:password-shown-once)).

بعد از تغییر، اتصال QGIS، GeoServer، برنامه‌ها و هر جای دیگری که رمز قدیمی را دارد باید به‌روز شود، وگرنه [خطای احراز هویت](kb:err-password-auth) می‌دهد. فقط مالک پایگاه داده رمز را عوض می‌کند.
