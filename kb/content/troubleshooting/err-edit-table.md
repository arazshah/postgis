| نشانه | علت | راه‌حل |
|---|---|---|
| دکمه‌ی «ویرایش جدول» نیست | شما مشاهده‌گر تیم هستید یا پایگاه داده فعال نیست (فقط‌خواندنی، منقضی یا معلق) | [نقش](kb:team-roles) را ویرایشگر کنید یا پایگاه داده را تمدید کنید |
| برچسب «فقط‌خواندنی» و توضیح «کلید اصلی ندارد» | جدول primary key ندارد | با [کنسول SQL](kb:sql-console): `ALTER TABLE t ADD PRIMARY KEY (id);` |
| «نما و جدول خارجی قابل ویرایش نیستند» | شیء یک view است | جدول اصلی را ویرایش کنید |
| «حالت ویرایش خاموش یا منقضی شده» | ۱۵ دقیقه بی‌کاری یا خروج | دوباره روشن کنید؛ پیش‌نویس‌ها حفظ شده‌اند |
| تعارض: «این سطر ... توسط کس دیگری تغییر کرده» | همکار، QGIS یا برنامه‌ای همان سطر را بعد از باز کردن شما عوض یا حذف کرد | آن تغییر را بردارید، صفحه را تازه کنید و دوباره ویرایش کنید |
| «ستون ... نباید خالی باشد» | ستون NOT NULL خالی مانده | مقدار بدهید (یا در افزودن، ستون دارای پیش‌فرض را خالی بگذارید) |
| «مقدار تکراری است» | ستون یکتا یا کلید اصلی با مقدار موجود برخورد دارد | مقدار دیگری بدهید |
| «مقدار برای نوع ستون معتبر نیست» | مثلاً متن در ستون عددی یا تاریخ نادرست (`2026-10-28`) | نوع ستون را در تب «ستون‌ها» ببینید |
| «کلید خارجی» | سطر به جدول دیگری وابسته است یا به سطری که نیست اشاره می‌کند | اول سطر وابسته را اصلاح کنید |
| هندسه نامعتبر | چندضلعی خودتقاطع و مانند آن | شکل را دوباره بکشید یا «ترمیم خودکار»؛ [توضیح](kb:invalid-geometry-fix) |
| «چند تکه ... ولی این ستون فقط یک تکه می‌پذیرد» | ترمیم، شکل را به چند تکه می‌شکند | شکل را ساده‌تر بکشید یا ستون را MultiPolygon کنید |
| «در هر ذخیره حداکثر ۵۰۰ تغییر» | سقف هر ذخیره | تغییرها را در چند مرحله ذخیره کنید |
| «بازگردانی ممکن نشد» | بعد از آن ذخیره، همان سطرها دوباره تغییر کرده‌اند | چیزی برگردانده نمی‌شود؛ دستی اصلاح کنید یا از [بکاپ](kb:backup-manual) بازگردانید |

در همه‌ی این حالت‌ها **چیزی نیمه‌کاره نوشته نمی‌شود**: اگر یک تغییر خطا بدهد، هیچ‌کدام ذخیره نمی‌شود.
