| نشانه | علت | راه‌حل |
|---|---|---|
| «برای هیستوگرام یک ستون عددی انتخاب کنید» | ستون متنی است | ستون را با `ALTER TABLE ... ALTER COLUMN ... TYPE numeric USING ...` عددی کنید |
| «برای سری زمانی یک ستون تاریخ انتخاب کنید» | ستون متنی یا عددی است | نوع ستون را به `date` یا `timestamp` ببرید |
| «داده‌ای برای نمایش نیست» | جدول خالی است، همه مقدارها NULL هستند، یا «فقط محدوده دیده‌شده» روشن است و کادر نقشه عارضه ندارد | «فقط محدوده دیده‌شده» را خاموش کنید یا به لایه بروید |
| «جدول ... در دسترس نیست» | جدول لایه حذف یا تغییر نام داده شده | [لایه را دوباره اضافه کنید](kb:err-map-layer-missing) |
| «پلن شما حداکثر ... نمودار» | سقف پلن | یک نمودار را حذف کنید یا [پلن را ارتقا دهید](kb:multi-layer-quota) |
| با کلیک روی نمودار چیزی روی نقشه برجسته نمی‌شود | لایه روشن نیست، یا نمودار هنوز ذخیره نشده و کاشی‌ها قدیمی‌اند | لایه را روشن کنید، «ذخیره» را بزنید و صفحه را تازه کنید |
| در نقشه عمومی نمودار خطا می‌دهد | [سقف روزانه درخواست](kb:daily-limits) پر است یا نقشه خصوصی است | سقف را ببینید یا نقشه را عمومی کنید |
| سری زمانی تاریخ‌ها را دیر یا زود نشان می‌دهد | ماه و روز بر اساس منطقه زمانی نشست پایگاه داده (معمولاً UTC) بریده می‌شود | برای ستون `timestamptz` که نزدیک نیمه‌شب ثبت شده، ستون `date` جدا بسازید |

نمودار نتیجه را یک دقیقه کش می‌کند؛ بعد از تغییر داده کمی صبر کنید یا صفحه را تازه کنید.
