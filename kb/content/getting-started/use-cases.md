## نمونه‌های مناسب

- **پایان‌نامه و پروژه درسی:** پایگاه داده‌ای که از QGIS و SQL قابل استفاده است، بدون نصب سرور.
- **نمونه اولیه WebGIS:** لایه‌ها را [به کاشی برداری، OGC API یا WMS/WFS](kb:publish-layer-overview) تبدیل کنید و در Leaflet، OpenLayers یا MapLibre نشان دهید.
- **نقشه قابل اشتراک:** [صفحه نقشه با لینک یا iframe](kb:map-builder) برای وبلاگ، ارائه یا گزارش.
- **جمع‌آوری داده میدانی:** [فرم موبایلی با GPS](kb:field-form) که بدون اینترنت هم کار می‌کند.
- **تحلیل مکانی:** [کوئری‌های SQL](kb:sql-console)، [ابزارهای تحلیل بدون SQL](kb:analysis-tools) و [مسیریابی](kb:routing-shortest-path).
- **آموزش:** استاد برای هر دانشجو پایگاه داده جدا می‌گیرد ([پلن کلاس](kb:classroom-overview)).
- **تیم کوچک مشاور یا شهرداری:** [دعوت همکاران](kb:team-roles) با نقش مشاهده‌گر یا ویرایشگر.

## چه زمانی احتیاط کنید؟

- پلن رایگان برای یادگیری و نمونه اولیه است؛ برای سرویس مهم، حجم بالا یا بکاپ ساعتی [پلن‌های پولی و سازمانی](kb:plans-overview) را ببینید.
- ذخیره داده طبقه‌بندی‌شده یا اطلاعات شخصی دیگران بدون مجوز طبق [قوانین استفاده](kb:data-ownership-privacy) ممنوع است.
