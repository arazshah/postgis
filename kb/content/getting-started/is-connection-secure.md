## لایه‌های امنیتی

- **رمزنگاری اتصال:** با SSL؛ در ابزار خود `sslmode=require` بگذارید ([حالت‌های SSL](kb:ssl-modes)).
- **جداسازی:** هر پایگاه داده نقش و رمز مخصوص خود را دارد و نقش شما به پایگاه داده کاربران دیگر یا پایگاه‌های سیستمی دسترسی ندارد.
- **مرورگر داده با نقش محدود:** مرورگر و کنسول SQL داخل سایت با مدیر سرور وصل نمی‌شوند، بلکه با یک نقش محدود غیرمدیر.
- **رمزها رمزنگاری‌شده نگه داشته می‌شوند** و کلید API و رمز پایگاه داده فقط یک بار به شما نشان داده می‌شوند.
- **دسترسی تیم:** [نقش‌های مشاهده‌گر و ویرایشگر](kb:team-roles) و [کاربران محدود پایگاه داده](kb:database-users).

## وظیفه شما

رمز را فاش نکنید، [کلید API را ایمن نگه دارید](kb:api-key-safety) و از داده مهم نسخه شخصی داشته باشید. مالکیت داده با شماست؛ جزئیات در [مالکیت داده و حریم خصوصی](kb:data-ownership-privacy).
