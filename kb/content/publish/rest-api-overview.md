🎬 **[ویدیوی راهنما: REST API و فرم جمع‌آوری میدانی](help:rest)** را ببینید (۰ دقیقه و ۴۳ ثانیه، بدون نیاز به صدا).

## آدرس‌ها

| مسیر | کار |
|---|---|
| `/rest/<سرویس>/` | فهرست جدول‌های فعال |
| `/rest/<سرویس>/<جدول>/` | فهرست ردیف‌ها |
| `/rest/<سرویس>/<جدول>/<کلید>/` | یک ردیف |

جدول‌ها را باید در صفحه **REST API و فرم میدانی** فعال کنید: روی «فعال‌سازی» جدول بزنید و یکی از سطح‌ها را انتخاب کنید: **غیرفعال**، **خواندن با کلید**، **خواندن عمومی**، **خواندن و افزودن** (مناسب [فرم میدانی](kb:field-form)) یا **دسترسی کامل**. «تنظیم دقیق» همان چهار اجازه را جدا جدا می‌دهد. ویرایش و حذف فقط برای جدولی که کلید اصلی تک‌ستونی دارد فعال می‌شود؛ بقیه را از [سلامت داده](kb:data-health) درست کنید. در زبانه‌ی **نمونه کد** جدول را انتخاب کنید تا نمونه‌ها با نام آن جدول عوض شود.

## پارامترها

| پارامتر | معنی |
|---|---|
| `limit` | تعداد ردیف (پیش‌فرض ۱۰۰، حداکثر ۱۰۰۰) |
| `offset` | صفحه‌بندی |
| `order` | ترتیب (نام ستون) |
| `bbox` | فیلتر مکانی (طول و عرض) |
| `col=v` | برابر |
| `col__gt`، `__gte`، `__lt`، `__lte`، `__ne` | مقایسه |
| `col__like` | جست‌وجوی متنی بدون حساسیت به حروف |

مثال: `/rest/demo/schools/?type=primary&students__gt=300&limit=20&order=name`

دسترسی با [کلید](kb:api-keys)؛ نوشتن: [REST write](kb:rest-write-access). اگر فقط خواندن استاندارد می‌خواهید، [OGC API](kb:ogc-api-features) را ببینید.
