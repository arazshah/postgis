title: لایه عمومی با لایه خصوصی چه فرقی دارد؟
summary: لایه عمومی بدون کلید برای همه قابل‌خواندن است. لایه خصوصی فقط با کلید API خوانده می‌شود. به‌طور پیش‌فرض لایه خصوصی است؛ فقط داده‌ای را عمومی کنید که می‌خواهید همه ببینند.

| | عمومی | خصوصی |
|---|---|---|
| دسترسی | هر کسی با آدرس | فقط با [کلید API](kb:api-keys) |
| مناسب | نقشه عمومی، داده باز | داده داخلی سازمان یا برنامه |
| کش و سرعت | بهتر (قابل کش) | کش محدودتر |

- ستون‌های منتشرنشده در هر دو حالت **هرگز** نمایش داده نمی‌شوند.
- لایه عمومی را هر کسی می‌تواند بخواند و حجم درخواست‌ها در [سقف روزانه](kb:daily-limits) حساب می‌شود.
- هر زمان می‌توانید تنظیم را عوض یا لایه را از انتشار خارج کنید.
- کلید در برنامه سمت مرورگر دیده می‌شود؛ [نکته امنیتی](kb:api-key-safety) را بخوانید.
