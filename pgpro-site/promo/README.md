| زمان | صحنه |
|---|---|
| ۰–۳٫۸ | «ژئوپایگاه معرفی می‌کند»: دستگاه‌های شناور، زوم روی دستگاه اصلی |
| ۳٫۸–۵٫۸ | دراپ: دستگاه روی سطح نرم فرود می‌آید، چراغ‌ها روشن، «pgpro» |
| ۵٫۸–۹٫۶ | نام محصول: «پایگاه داده مکانی پرو»، PostGIS آفلاین، داخل شبکه‌ی سازمان |

| ۱۳٫۴–۱۷٫۳ | فیلم دستگاه واقعی: کابل‌ها، صفحه‌ی آماده‌سازی، لپ‌تاپ و دستگاه |
| ۱۷٫۳–۲۱٫۱ | سایت pgpro.ir در مرورگر و گوشی |

| ۲۸٫۸–۳۵٫۵ | پایان: لوگو، پیش‌فروش، pgpro.ir |

## ساخت دوباره
- موسیقی کاملاً سنتز است (`src/music.py`، numpy/scipy؛ بدون نمونه‌ی صوتی و بدون حق نشر).
- انیمیشن: `src/stage.html` + `src/anim.js` (تابع `render(t)`)، فریم‌به‌فریم با Playwright (`src/render.js`) و سپس ffmpeg.
- تصویرها: اسکرین‌شات واقعی pgpro.ir و postgis.ir، عکس و ویدیوی دستگاه، `device.svg` و `logo.svg` سایت.
