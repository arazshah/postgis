روش ۱: DB Manager در QGIS (ساده‌ترین)

  1. لایه Shapefile یا GeoPackage را در QGIS باز کنید.
  2. از منوی Database › DB Manager اتصال خود را انتخاب کنید.
  3. دکمه Import Layer/File را بزنید، لایه را انتخاب و نام جدول را بنویسید.
  4. تیک‌های Create spatial index و Convert field names to lowercase را بزنید.
  5. اگر داده فارسی است، Encoding را روی UTF-8 یا windows-1256 بگذارید.

روش ۲: ogr2ogr (برای فایل‌های بزرگ)

ogr2ogr -f PostgreSQL PG:"host=HOST port=5432 dbname=DB user=USER password=PASS sslmode=require" \
  roads.shp -nln roads -nlt PROMOTE_TO_MULTI -lco GEOMETRY_NAME=geom -t_srs EPSG:4326 -progress

دستور دقیق با اطلاعات خودتان در زبانه «ورود Shapefile» صفحه پایگاه داده آماده است.

روش ۳: shp2pgsql

shp2pgsql -s 32639 -I -W UTF-8 parcels.shp public.parcels | psql "host=HOST dbname=DB user=USER sslmode=require"
بعد از وارد کردن داده، اگر نمایه مکانی نساخته‌اید حتماً بسازید؛ بدون آن کوئری‌ها کند می‌شوند:
CREATE INDEX ON parcels USING gist (geom);
