۱. ساخت حساب

از بالای صفحه «ورود / ثبت‌نام» را بزنید، شماره موبایل را وارد کنید و کد پیامک‌شده را بنویسید. بار اول نام خود را هم وارد می‌کنید. رمز عبور برای ورود به سایت لازم نیست.

۲. ساخت پایگاه داده

بعد از ثبت‌نام مستقیم به فرم ساخت پایگاه داده می‌روید:

  • نام: حروف کوچک انگلیسی، عدد و _؛ مثلاً tehran_parcels. یک پیشوند کوتاه خودکار به آن اضافه می‌شود.
  • رمز: می‌توانید «رمز تصادفی» را بزنید. این رمز فقط یک بار بعد از ساخت نمایش داده می‌شود.
  • افزونه‌ها: PostGIS پیش‌فرض انتخاب شده است. برای مسیریابی pgRouting و برای کاداستر توپولوژی را هم انتخاب کنید.

۳. گرفتن اطلاعات اتصال

در صفحه پایگاه داده، میزبان، پورت، نام پایگاه داده و نام کاربری را می‌بینید. برای QGIS، GeoServer، Python و ogr2ogr نمونه آماده و دکمه کپی دارید.

نام کاربری و نام پایگاه داده جدا هستند (مثلاً پایگاه داده gp_tehran و کاربر gp_tehran_user). هر کاربر فقط به پایگاه داده خودش دسترسی دارد.

۴. وارد کردن داده

ساده‌ترین راه، DB Manager در QGIS است. در آموزش «وارد کردن Shapefile» هر سه روش توضیح داده شده است.
