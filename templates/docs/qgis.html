افزودن اتصال

  1. QGIS را باز کنید (نسخه ۳٫۲۸ یا جدیدتر پیشنهاد می‌شود).
  2. در پنل Browser روی PostgreSQL راست‌کلیک کنید و New Connection… را بزنید.
  3. در فیلد Name یک نام دلخواه بنویسید.
  4. Host، Port و Database را از صفحه پایگاه داده خود کپی کنید.
  5. SSL mode را روی require بگذارید.
  6. در بخش Authentication زبانه Basic را باز کنید، نام کاربری و رمز را وارد و تیک Store را بزنید.
  7. Test Connection را بزنید. اگر پیام موفقیت آمد، OK.

نمایش لایه

اتصال جدید را در Browser باز کنید، روی schema به نام public بروید و جدول را روی نقشه بکشید.
