ساخت Store

  1. در GeoServer به Stores › Add new Store بروید و PostGIS را انتخاب کنید.
  2. یک Workspace انتخاب و برای Store نام بگذارید.
  3. مقادیر host، port، database، user و passwd را از زبانه GeoServer صفحه پایگاه داده کپی کنید. schema را public بگذارید.
  4. SSL mode را روی REQUIRE بگذارید.
  5. max connections را ۳ و min connections را ۱ بگذارید تا از سقف اتصال پلن عبور نکنید.
  6. Save را بزنید.

انتشار لایه

بعد از ذخیره Store، فهرست جدول‌ها نمایش داده می‌شود. کنار جدول Publish را بزنید، در بخش Bounding Boxes روی Compute from data کلیک و ذخیره کنید. لایه حالا از طریق WMS و WFS در دسترس است.

برای WebGIS پرترافیک، کش کاشی (GeoWebCache) را فعال کنید تا هر بار به پایگاه داده درخواست نرود.
