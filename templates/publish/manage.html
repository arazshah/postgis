اتصال از نرم‌افزار و کد

آدرس سرویس OGC API این پایگاه داده (همه‌ی لایه‌ها):

{{ base }}/ogc/{{ service.slug }}/

لایه‌ی نمونه را انتخاب کنید تا نمونه‌ها با آدرس همان لایه عوض شود:

{% for l in published %}{% endfor %} 
<link href="https://unpkg.com/maplibre-gl@4.7.1/dist/maplibre-gl.css" rel="stylesheet">
<script src="https://unpkg.com/maplibre-gl@4.7.1/dist/maplibre-gl.js"></script>
<div id="map" style="height:500px"></div>
<script>
const map = new maplibregl.Map({
  container: "map",
  style: {version: 8, sources: {}, layers: []},
  center: [51.39, 35.69], zoom: 10
});
map.on("load", () => {
  map.addSource("{{ sample.table }}", {type: "vector", url: "{{ base }}/tiles/{{ sample.slug }}.json"});
  map.addLayer({id: "{{ sample.table }}", type: "circle", source: "{{ sample.table }}",
                "source-layer": "{{ sample.collection_id }}", paint: {"circle-color": "#0F5C59"}});
});
</script>

برای خط از type: "line" و برای چندضلعی از "fill" استفاده کنید.

import VectorTileLayer from "ol/layer/VectorTile";
import VectorTileSource from "ol/source/VectorTile";
import MVT from "ol/format/MVT";

const layer = new VectorTileLayer({
  source: new VectorTileSource({
    format: new MVT(),
    url: "{{ base }}/tiles/{{ sample.slug }}/{z}/{x}/{y}.mvt",
  }),
});
map.addLayer(layer);
fetch("{{ base }}/ogc/{{ service.slug }}/collections/{{ sample.collection_id }}/items?limit=1000")
  .then(r => r.json())
  .then(data => L.geoJSON(data, {
    onEachFeature: (f, l) => l.bindPopup(JSON.stringify(f.properties))
  }).addTo(map));

برای لایه‌های بزرگ در Leaflet از افزونه Leaflet.VectorGrid با آدرس کاشی برداری استفاده کنید.

  1. OGC API - Features: در Data Source Manager بخش WFS / OGC API - Features را باز کنید، اتصال جدید بسازید و آدرس سرویس بالا را بگذارید. برای لایه خصوصی در بخش Authentication یک پیکربندی Basic بسازید و کلید API را در Password بگذارید.
  2. کاشی برداری: در Browser روی Vector Tiles راست‌کلیک کنید، New Generic Connection و آدرس XYZ لایه را بگذارید.
import geopandas as gpd

url = "{{ base }}/ogc/{{ service.slug }}/collections/{{ sample.collection_id }}/items?limit=5000"
gdf = gpd.read_file(url)   # برای لایه خصوصی: url + "&key=کلید_شما"
print(gdf.head())
