اتصال در QGIS، ArcGIS و کد
  1. QGIS: در Browser روی WMS/WMTS (یا WFS / OGC API - Features) راست‌کلیک › New Connection، آدرس بالا را بدهید.
  2. ArcGIS Pro: Insert › Connections › Server › New WMS Server.
  3. Leaflet:
L.tileLayer.wms("{{ url }}", {
  layers: "{{ root }}", format: "image/png", transparent: true, version: "1.3.0"
}).addTo(map);
# OpenLayers
new ol.layer.Tile({source: new ol.source.TileWMS({
  url: "{{ url }}", params: {LAYERS: "{{ root }}", TILED: true}
})});
