# دروازه‌ی ماهواره (satgate)

سرویس کوچکی که **روی یک سرور خارج از ایران** اجرا می‌شود و کار سنگین تصویر ماهواره‌ای را انجام می‌دهد:
جست‌وجو در کاتالوگ STAC (Earth Search، رایگان و بدون ثبت‌نام)، خواندن **فقط تکه‌ی لازم** از تصویرهای COG،
ساخت محصول (رنگ طبیعی، فروسرخ کاذب، NDVI، همه‌ی باندها، DEM) و تحویل فایل برش‌خورده به پنل.
سرور ایران فقط دستور می‌دهد و فایل آماده را برمی‌دارد؛ GDAL آن همچنان از اینترنت جداست.

```
پنل (ایران) ──امضا HMAC──► دروازه ──► Earth Search / S3
     ▲                        │ برش و ساخت محصول (≤ چند ده مگابایت)
     └── هوک «آماده شد» ◄─────┘   (اگر نرسید، پنل هر دقیقه وضعیت را می‌پرسد)
     └── دانلود فایل (Range) ─► پنل ← gdalinfo + تبدیل به COG ← حذف از دروازه
```

## نصب (روی سرور خارجی)
۱. Docker نصب کنید و ایمیج را بگیرید (یا `docker build -f satgate/Dockerfile -t satgate .` از ریشه‌ی مخزن).
۲. کلید مشترک بسازید:
```bash
python3 -c "import secrets; print(secrets.token_urlsafe(48))"
```
۳. `satgate/.env.example` را به `.env` کپی و پر کنید، سپس:
```bash
docker compose -f satgate/docker-compose.yml --env-file .env up -d
```
۴. جلوی پورت ۸۰۸۰ یک پراکسی با TLS بگذارید (مثلاً دامنه‌ی `sat.example.com`). بهتر است فایروال فقط IP سرور ایران را بپذیرد.

## تنظیم پنل (سرور ایران)
در Coolify برای `web` و `worker` این متغیرها را بگذارید:

| متغیر | مقدار |
|---|---|
| `SATGATE_URL` | `https://sat.example.com` |
| `SATGATE_SECRET` | همان کلید مشترک |

سپس **روی سرور ایران** آزمون دسترسی (فاز ۰) را اجرا کنید:
```bash
python manage.py sat_probe
```
این فرمان سلامت دروازه، درستی کلید، دسترسی دروازه به کاتالوگ و داده، و سرعت دانلود به ایران را می‌سنجد.
اگر همه‌ی مرحله‌ها موفق بود، بخش «تصویر ماهواره‌ای» برای کاربران فعال می‌شود (تا وقتی `SATGATE_URL` خالی است «به‌زودی» نشان داده می‌شود).

## امنیت و هزینه
- همه‌ی مسیرها جز `/v1/health` امضای `X-Sat-Sig` (HMAC-SHA256 روی زمان، روش، مسیر و چکیده‌ی بدنه) و حداکثر ۲ دقیقه اختلاف ساعت می‌خواهند.
- دروازه فقط به نشانی پنلی که خودش تنظیم شده هوک می‌فرستد، نه هر نشانی که در درخواست بیاید.
- هیچ داده‌ی مشتری روی دروازه نمی‌ماند: فقط محدوده و تصویر برش‌خورده؛ خروجی بعد از تحویل یا حداکثر `SATGATE_KEEP_HOURS` ساعت پاک می‌شود.
- سقف‌ها: `SATGATE_MAX_KM2` (مساحت)، `SATGATE_MAX_MB` (حجم خروجی)، `SATGATE_WORKERS` (برش هم‌زمان)؛ پنل هم سقف پلن کاربر را می‌فرستد و کمینه‌ی دو سقف اعمال می‌شود.
- ترافیک: برش‌ها کوچک‌اند (معمولاً ۱۰ تا ۵۰ مگابایت)، پس هزار درخواست در ماه حدود ۵۰ گیگابایت است.
- اگر `SATGATE_STAC_URL` را عوض کنید می‌شود از کاتالوگ دیگری با همان قرارداد STAC استفاده کرد.

## توسعه
```bash
python -m unittest satgate.tests.test_gateway     # آزمون‌ها با تصویر ساختگی؛ بدون اینترنت
gunicorn satgate.app:application --workers 1 --threads 8
```
فقط **یک** پردازش gunicorn اجرا شود؛ صف کارها در حافظه است (وضعیت و فایل‌ها روی دیسک می‌مانند).
