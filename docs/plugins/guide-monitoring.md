# راهنمای گام‌به‌گام: ساخت پلاگین «مانیتورینگ آنلاین»

هدف: دستگاه‌ها (GPS، سنسور، هر سامانه‌ی بیرونی) داده می‌فرستند؛ مشتری در صفحه‌ی پایگاه داده‌اش آخرین وضعیت، شمارنده‌ها، نقشه و جدول را زنده می‌بیند.
این نمونه **بدون کد پایتون** است (سطح ۱ + `[[ingest]]`). فایل‌های نمونه: `docs/plugins/examples/monitoring/`.

## تصویر کلی (چهار مفهوم)
| مفهوم | چیست |
|---|---|
| **پلاگین** | قابلیتی که به سامانه افزوده می‌شود و مدیر روشن/خاموش یا به مشتریِ مشخص محدودش می‌کند. |
| **بسته (`.gpkgx`)** | فایل zip امضاشده‌ی پلاگین. پنل فقط بسته‌ی امضاشده با کلید ناشر شما را قبول می‌کند. |
| **کلید ناشر** | جفت‌کلید Ed25519: **خصوصی** (فقط پیش شما، برای امضا) و **عمومی** (در پنل، برای راستی‌آزمایی). |
| **استودیو** | فرم پنل برای ساخت پلاگین ساده؛ خروجی‌اش بسته‌ی **بدون امضا** است. |

## گام ۱ — کلید ناشر (یک‌بار)
1. پنل ← «کلیدهای ناشر» (`/manage/kernel/publisherkey/`). نام ناشر را بنویسید (مثلاً `araz`، حروف کوچک لاتین).
2. «ساخت جفت‌کلید و دانلود کلید خصوصی». فایل `araz.key` دانلود می‌شود و کلید عمومی در فرم پر می‌شود.
3. «افزودن کلید عمومی» (تأیید تازه‌ی 2FA می‌خواهد).
4. `araz.key` را جای امن نگه دارید (رمزنگار، نه ایمیل/چت/مخزن). **اگر گم شود** باید کلید تازه بسازید و بسته‌ها را دوباره امضا کنید؛ اگر **لو برود** کلید را در پنل حذف کنید.

## گام ۲ — جدول داده در پایگاه مشتری
`[[ingest]]` فقط در **جدول موجود** می‌نویسد. در صفحه‌ی SQL همان پایگاه (یا هر ابزار دیگر):
```sql
CREATE TABLE monitor_points (
  id bigserial PRIMARY KEY,
  device text NOT NULL,
  lat double precision NOT NULL,
  lon double precision NOT NULL,
  speed double precision,
  at timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX ON monitor_points (device, at DESC);
```
زمان (`at`) را خود پایگاه می‌گذارد (دستگاه نمی‌فرستد).

## گام ۳ — فایل‌های بسته
پوشه‌ی `monitoring/` با دو فایل (نمونه‌ی کامل در `docs/plugins/examples/monitoring/`):
- `plugin.toml`: `id`، `name`، `version` (هر نسخه‌ی تازه بالاتر)، `tier = 1`، فهرست صفحه‌ها.
- `pages/live.toml`: دو شمارنده (`kpi`)، نقشه‌ی آخرین موقعیت (`map`)، جدول ۲۰ رکورد آخر (`table`)، و `[[ingest]]` (فیلدهای `device`، `lat`، `lon`، `speed`).

قواعد مهم: SQL فقط `SELECT`، یک دستور. صفحه‌ی دارای `[[ingest]]` سطح `editor` می‌خواهد. نقشه ستون `geom` می‌خواهد. مرجع کامل: `docs/plugins/page-kit.md`، `docs/plugins/ingest.md`.
> **استودیو:** می‌توانید به‌جای نوشتن دستی، در پنل ← «استودیوی پلاگین» پلاگین بسازید، صفحه را از قالب «پایش» بیفزایید و «ذخیره و بررسی» بزنید؛ سپس «خروجی» zip بدون امضا می‌دهد. `[[ingest]]` را بعد از خروجی در `pages/live.toml` بیفزایید (استودیو هنوز فرم جدا برای آن ندارد).

## گام ۴ — امضا (روی رایانه‌ی خودتان)
سرور کلید خصوصی شما را نمی‌بیند. روی رایانه‌ی خودتان (Python 3.13):
```bash
git clone https://github.com/arazshah/postgis && cd postgis
pip install -r requirements.txt
python manage.py plugin_pack /مسیر/monitoring --key /مسیر/araz.key --publisher araz --out monitoring-1.0.0.gpkgx
```
خروجی همه‌ی مرحله‌های بررسی را با ✓ نشان می‌دهد. اگر خطایی بود، متن فارسی می‌گوید کدام فایل/خط.
(برای بررسی بسته‌ی دیگر: `python manage.py plugin_check monitoring-1.0.0.gpkgx` با `PLUGIN_PUBLISHER_KEYS="araz=<کلید عمومی>"`.)

## گام ۵ — بارگذاری و فعال‌سازی (پنل)
1. «بسته‌های پلاگین» ← بارگذاری ← فایل `.gpkgx`. بررسی خودکار فوراً اجرا و گزارش می‌شود (بسته‌ی بدون امضای معتبر رد می‌شود).
2. **تأیید و فعال‌سازی:** مدیری غیر از بارگذارنده (اصل دونفره). اگر فقط یک مدیر دارید: تنظیم `PLUGIN_SELF_APPROVAL=1` (فقط تیم یک‌نفره؛ ریسکش را بپذیرید).
3. پلاگین «محدود و بدون مجوز» ساخته می‌شود؛ در «پلاگین‌ها و مجوزها» ← «مانیتورینگ آنلاین» ← **مجوز** بدهید (به یک پایگاه، کاربر، سازمان، پلن، یا همه).
4. پایگاه داده را باز کنید؛ در ریل بخش «مانیتورینگ آنلاین» دیده می‌شود (گروه «داده»).

## گام ۶ — توکن دستگاه
در صفحه‌ی «مانیتورینگ آنلاین» همان پایگاه، کارت «دریافت داده‌ی دستگاه» ← «ساخت توکن» (فقط **مالک** پایگاه). توکن (`gpi_…`) **یک‌بار** نشان داده می‌شود؛ کپی کنید.

## گام ۷ — آزمون
```bash
curl -X POST https://دامنه-شما/ingest/ \
  -H "Authorization: Bearer gpi_..." -H "Content-Type: application/json" \
  -d '[{"device":"d1","lat":35.70,"lon":51.40,"speed":42},{"device":"d2","lat":35.75,"lon":51.45}]'
# ← {"ok": true, "inserted": 2}
```
صفحه هر ۱۵ ثانیه خودش تازه می‌شود (`refresh = 15`). خطاها: ۴۰۴ = توکن/دسترسی، ۴۲۲ = ردیف نامعتبر (هیچ ردیفی نوشته نمی‌شود)، ۴۲۹ = سقف نرخ.

## به‌روزرسانی و بازگشت
- نسخه‌ی تازه: `version = "1.0.1"` ← دوباره پک و بارگذاری ← فعال‌سازی. نسخه‌ی قبلی می‌ماند.
- بازگشت: نسخه‌ی قبلی را دوباره «فعال‌سازی» کنید. خاموشی آنی: «پلاگین‌ها و مجوزها» ← خاموش.
- خطای پیاپی پلاگین را قطع‌کن خودکار خاموش می‌کند (کارت «نیاز به توجه»).

## چه وقت سطح ۲ یا ۳؟
- اگر دستگاه قالب غیر JSON می‌فرستد (متن، باینری): `handler` در `[[ingest]]` (سطح ۲، `docs/plugins/tier2.md`).
- اگر منطق پیچیده، مدل/جدول خودتان یا صفحه‌ی سفارشی می‌خواهید: سطح ۳ (`docs/plugins/tier3.md`)، با `manage.py ext_new` و PR، بدون امضا.
