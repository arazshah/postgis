# گزارش PDF صفحه `[[reports]]`

(ADR-0009 مرحله‌ی ۴)

دکمه‌ی «گزارش PDF» در بالای صفحه؛ همان داده و همان فیلترهای فعلی صفحه را به یک PDF فارسی راست‌به‌چپ (A4) تبدیل می‌کند.

```toml
[[reports]]
key = "monthly"
title = "گزارش ماهانه‌ی ایستگاه‌ها"
subtitle = "وضعیت سنجنده‌ها"     # اختیاری
blocks = [1, 2, 4]              # شماره‌ی ۱-پایه‌ی بلوک‌های صفحه؛ خالی = همه
orientation = "portrait"        # portrait | landscape
button = "گزارش PDF"
```

محتوا: عنوان، نام سایت و پایگاه، **تاریخ شمسی**، فیلترهای فعال، شمارنده‌ها، جدول (سرستون در هر صفحه تکرار می‌شود)، نمودار میله‌ای، متن و **نقشه‌ی برداری** (SVG: مرکاتور، شبکه‌ی طول/عرض، مقیاس، فلش شمال؛ بدون نقشه‌ی پایه). رقم‌ها فارسی؛ فونت Vazirmatn جاسازی می‌شود. شماره‌ی صفحه پایین هر صفحه است.

## چیدمان قابل‌ویرایش توسط کاربر
کاربر (سطح ویرایشگر) از دکمه‌ی «چیدمان» بالای صفحه، گزارش را خودش می‌چیند و ذخیره می‌کند (مشترک بین ویرایشگران همان پایگاه):
- **عنصرها:** لوگو، عنوان و زیرعنوان، متن دلخواه (چندبندی، با جای‌نگهدارهای `{date}`، `{db}`، `{site}`، `{page}`، `{filters}`)، اطلاعات گزارش، بخش داده (هر بلوک صفحه: شمارنده، جدول، نمودار، نقشه؛ با عنوان دلخواه یا بدون عنوان و ارتفاع نقشه)، خط جداکننده، فاصله و صفحه‌ی جدید. افزودن، حذف و جابه‌جایی با دکمه‌های بالا/پایین؛ تا ۴۰ عنصر.
- **ظاهر:** چینش راست/وسط/چپ، اندازه‌ی چهارگانه، رنگ از چهار رنگ سیستم (اصلی، تأکیدی، تیره، کمرنگ)، پررنگ.
- **صفحه:** عمودی/افقی، حاشیه، مقیاس نوشته‌ها، متن پاورقی و شماره‌ی صفحه.
- **لوگو:** بارگذاری PNG/JPEG (تا ۱ مگابایت) که با Pillow بازکدگذاری و کوچک می‌شود (متادیتا و SVG رد می‌شود).
- **پیش‌نمایش زنده** با داده و فیلترهای فعلی صفحه (iframe بدون اسکریپت با CSP بسته)، و «بازنشانی» به چیدمان پیش‌فرض مشخصات.
- **خروجی:** PDF یا **تصویر PNG** (`?page=N` برای صفحه‌ی دلخواه) از همان چیدمان ذخیره‌شده؛ دکمه‌های «PDF» و «تصویر» بالای صفحه و داخل ویرایشگر.

چیدمان یک JSON کوچک و کاملاً اعتبارسنجی‌شده است (`kernel/reportlayout.py`)؛ **HTML/CSS/SVG آزاد پذیرفته نمی‌شود** و همه‌ی متن‌ها در خروجی escape می‌شوند (متن پاورقی که داخل CSS می‌رود فقط نویسه‌های بی‌خطر نگه می‌دارد). چیدمان و لوگو با حذف پایگاه پاک می‌شود.

## امنیت و سقف‌ها
- همه‌ی متن‌ها escape می‌شوند. **واکشی بسته است:** فقط دو فونت داخلی؛ نشانی شبکه، فایل محلی و `data:` هیچ‌وقت خوانده نمی‌شود.
- حداکثر ۴۰ صفحه؛ جدول ۲۰۰ ردیف؛ نقشه ۲۰۰۰ عارضه و ۶۰ هزار رأس؛ ۶ گزارش در دقیقه برای هر کاربر؛ سقف ماهانه‌ی مجوز `report_pdfs_per_month`.
- فقط‌خواندنی است؛ سطح دسترسی همان سطح صفحه است. هر گزارش در گزارش فعالیت پایگاه ثبت می‌شود.
- پیام خطا ثابت و کوتاه است (جزئیات فنی نشان داده نمی‌شود).

## نیازمندی سرور
کتابخانه‌ی WeasyPrint و بسته‌های pango در ایمیج (Dockerfile) هست؛ نیاز به تنظیم Coolify نیست.

## حد فعلی
جابه‌جایی عنصر با کشیدن‌ورها نیست (دکمه‌ی بالا/پایین)؛ چیدمان فقط یک نسخه‌ی ذخیره‌شده برای هر پایگاه دارد. تولید همزمان در درخواست وب است (برای صفحه‌های معمول چند ثانیه)؛ ارسال خودکار هفتگی با ایمیل/پیام‌رسان و نقشه‌ی پایه هنوز نیست.
