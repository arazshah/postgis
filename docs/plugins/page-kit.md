# کیت صفحه: صفحه‌ی تازه برای پلاگین بدون نوشتن HTML

مرجع: `docs/adr/0004-kernel-and-plugins.md`. پلاگین صفحه را با **مشخصات** (داده) توصیف می‌کند و هسته آن را با اجزای سیستم طراحی می‌سازد؛
پس راست‌به‌چپ، ۴۰۰ پیکسل، حالت خالی و خطا خودکار درست است. صفحه در ریل پایگاه داده می‌آید و آدرسش
`dashboard/<pk>/p/<پلاگین>/<صفحه>/` است.

## مشخصات (TOML یا dict)

```toml
key = "live"                      # یکتا در پلاگین؛ حروف کوچک لاتین، رقم و _
title = "پایش آنلاین ناوگان"
subtitle = "آخرین موقعیت دستگاه‌ها"
icon = "pulse"                    # از core/icons.py
group = "data"                    # data | share | manage  (گروه منوی ریل)
need = "viewer"                   # viewer | editor | owner
order = 100
refresh = 15                      # ثانیه (۵ تا ۳۶۰۰)؛ ۰ = بدون تازه‌سازی خودکار

[[params]]                        # فیلترهای بالای صفحه
name = "hours"
kind = "choice"                   # int | number | text | choice | layer
label = "بازه"
default = "1"
choices = [["1", "یک ساعت"], ["6", "شش ساعت"]]

[[params]]
name = "t"
kind = "layer"                    # فهرست جدول‌های پایگاه؛ فقط با {t} در SQL می‌آید
label = "جدول موقعیت‌ها"

[[blocks]]
kind = "kpi"                      # text | kpi | table | bars | map
title = "دستگاه فعال"
sql = "select count(distinct device) from {t} where at > now() - make_interval(hours => %(hours)s::int)"
unit = "دستگاه"
```

## بلوک‌ها
| نوع | منبع (`sql`) | نمایش |
|---|---|---|
| `text` | ندارد؛ `text` (بندها با خط خالی جدا می‌شوند) | متن |
| `kpi` | اولین ستون اولین ردیف | عدد درشت + `unit` |
| `table` | ردیف‌ها (حداکثر ۲۰۰)؛ `columns = [["ستون", "برچسب"]]` اختیاری | جدول |
| `bars` | ستون‌های `label` و `value` (حداکثر ۵۰) | میله‌ها |
| `map` | ستون `geom` (هر SRID؛ به ۴۳۲۶ تبدیل می‌شود) + ستون‌های ویژگی (حداکثر ۲۰۰۰) | نقشه |

عرض: `full` (پیش‌فرض)، `half`، `third` (پیش‌فرض kpi). خطای یک بلوک فقط همان بلوک را به پیام کوتاه تبدیل می‌کند.

## امنیت SQL (الزامی بدانید)
- فقط `SELECT`/`WITH`؛ با **نقش محدود مرورگر** همان مشتری، در **تراکنش فقط‌خواندنی**، با حد زمانی ۸ ثانیه و سقف ردیف.
- فقط **یک دستور**: SQL با پروتکل گسترده اجرا می‌شود؛ `;` و چند دستور رد می‌شود.
- مقدار پارامتر را همیشه با `%(نام)s` بیاورید (bind می‌شود). نام جدول فقط از پارامتر `layer` و با `{نام}`.
- `%` واقعی را `%%` و `{`/`}` واقعی را `{{`/`}}` بنویسید.

## ثبت از کد
```python
from kernel import pagekit
pagekit.register("myplugin", pagekit.parse_page("myplugin", spec_dict))
```
خطای مشخصات = `SpecError` با پیام فارسی (در بسته‌ی بارگذاری‌شده، گزارش بررسی). دسترسی صفحه را موتور مجوز (`kernel.entitlements`)
کنترل می‌کند: پلاگین خاموش یا بدون مجوز، منو و آدرس صفحه را ندارد.
