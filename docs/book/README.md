# کتاب «پایگاه داده مکانی ابری»
### مرجع جامع سامانه‌ی اطلاعات مکانی، سنجش از دور و SQL مکانی؛ از صفر تا متخصص

نسخه‌ی چاپی: `out/book.pdf` (جلد رو + متن + جلد پشت، قطع وزیری ۱۷×۲۴) و `out/cover-spread.pdf` (جلد کامل با عطف برای چاپخانه).
در متن کتاب نام تجاری سامانه به کار نمی‌رود؛ همه‌جا «پایگاه داده مکانی ابری» است (`build.py --check` این را بررسی می‌کند).

## ساخت

```bash
pip install -r requirements-dev.txt pyyaml        # و pandoc، poppler-utils (pdftotext، pdfunite)، Playwright/Chromium
python docs/book/build.py            # PDF کامل
python docs/book/build.py --html     # فقط HTML
python docs/book/build.py --check    # اجرای همه‌ی SQLها، وجود تصویرها، نبود نام تجاری
docs/book/shots.sh                   # تصویرهای رابط از محیط نمایشی (PostgreSQL+PostGIS محلی لازم است)
```

- **SQL اجراشده:** کدهای ```` ```{.sql .run} ```` روی پایگاه نمونه در تراکنشی که در پایان برگردانده می‌شود اجرا و جدول نتیجه زیرشان چاپ می‌شود (`rows=n` تعداد سطر؛
  `setup=نام` یک SQL آماده‌سازی از `setup/` را پنهانی پیش از کد اجرا می‌کند). نتیجه‌ها در `results/` نگه داشته می‌شوند تا ساخت بدون پایگاه هم ممکن باشد؛ `BOOK_RERUN=1`
  همه را دوباره اجرا می‌کند. اتصال: `BOOK_PG` (پیش‌فرض پایگاه نمایشی).
- **تصویرها:** `shots.js` با Playwright از رابط واقعی روی داده‌ی نمایشی (`docs/help-video/demo.py`) با نام سایت «پایگاه داده مکانی ابری» و نشانی `db.example.com`.
- **نمودارها:** SVGهای `figures/` درون صفحه قرار می‌گیرند تا قلم فارسی در آن‌ها هم به کار برود.
- **شماره‌ی فصل** از نام فایل (`31-rs-physics.md` = فصل ۳۱) است.
- **داده‌ی نمونه‌ی خواننده:** `data/` (سه GeoJSON، `sample.sql`، `ndvi_parcels.sql`، `survey_points.sql`).
