## سطح هر فصل

کنار عنوان هر فصل سه دایره می‌بینید. یک دایره‌ی رنگی یعنی **مبتدی** (بدون هیچ پیش‌زمینه)، دو دایره یعنی **متوسط**
(فصل‌های پیش‌نیاز را خوانده‌اید) و سه دایره یعنی **پیشرفته** (برای متخصص و برنامه‌نویس). لازم نیست کتاب را از اول تا آخر
بخوانید؛ مسیر مطالعه‌ی خودتان را از جدول زیر انتخاب کنید.

## کادرهای کتاب

::: note
**نکته:** راهی کوتاه‌تر، ترفندی کاربردی یا توضیحی که فهم موضوع را آسان‌تر می‌کند.
:::

::: warn
**هشدار:** کاری که اگر اشتباه انجام شود داده را خراب یا نتیجه را غلط می‌کند.
:::

::: know
**بدانید:** پیش‌زمینه‌ی نظری یا تاریخی که برای انجام کار لازم نیست، اما برای «فهمیدن» آن لازم است.
:::

::: pro
**سطح حرفه‌ای:** جزئیات فنی برای خواننده‌ی پیشرفته؛ در خواندن اول می‌توانید از آن بگذرید.
:::

::: real
**در دنیای واقعی:** نمونه‌ای از کاربرد موضوع در یک پروژه یا سازمان واقعی.
:::

::: try
**خودتان امتحان کنید:** کار کوتاهی که همان‌جا در سامانه انجام می‌دهید تا مطلب تثبیت شود.
:::

::: teach
**برای مدرس:** زمان پیشنهادی کلاس، نکته‌ی تدریس و تمرین کلاسی.
:::

## قراردادهای نگارشی

- نام منوها، دکمه‌ها و زبانه‌های رابط داخل گیومه می‌آید: «اجرای SQL»، «ورود فایل».
- مسیر رسیدن به یک صفحه با علامت ← نوشته می‌شود: منوی کناری ← داده ← جدول‌ها.
- کد، نام جدول و ستون با قلم ثابت‌عرض و چپ‌به‌راست نوشته می‌شود: `schools`، `ST_Buffer`.
- کلیدواژه‌های SQL با حروف بزرگ (`SELECT`، `WHERE`) و نام جدول و ستون با حروف کوچک نوشته شده است؛ SQL به بزرگی و کوچکی
  کلیدواژه‌ها حساس نیست و این فقط برای خوانایی است.
- زیر بسیاری از کدها جدول کوچکی با قلم ثابت‌عرض آمده است: **نتیجه‌ی واقعی اجرای همان کد روی داده‌ی نمونه.** اگر نتیجه
  بیش از چند سطر باشد، فقط سطرهای اول و تعداد کل نشان داده شده است.
- اصطلاح انگلیسی بار اول کنار معادل فارسی آمده است و فهرست کامل آن‌ها در واژه‌نامه‌ی پایان کتاب است.

## داده‌ی نمونه

همه‌ی مثال‌ها روی یک پایگاه داده با نام `tehran_gis` اجرا شده‌اند. این پایگاه شش جدول دارد:

| جدول | نوع هندسه | تعداد | ستون‌های مهم |
|---|---|---|---|
| `schools` | نقطه | ۱۸۰ | `name`، `level` (مقطع)، `students` |
| `metro_stations` | نقطه | ۸۰ | `name`، `line` |
| `parks` | چندضلعی | ۳۵ | `name`، `area_ha` |
| `neighborhoods` | چندضلعی | ۶ | `name`، `population` |
| `health_centers` | نقطه | ۴۰ | `name`، `type`، `beds` |
| `parcels` | چندضلعی | ۱۲ | `id`، `name` (قطعه‌های کشاورزی) |

همه‌ی جدول‌ها در سیستم مختصات جغرافیایی WGS84 (کد ۴۳۲۶) ذخیره شده‌اند. این داده‌ها برای آموزش ساخته شده‌اند و جای واقعی
مدرسه یا ایستگاهی را نشان نمی‌دهند. فصل ۷ نشان می‌دهد چگونه این فایل‌ها را وارد پایگاه خود کنید.
