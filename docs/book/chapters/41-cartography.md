## نقشه، استدلال بصری

نقشه فقط «نمایش داده» نیست؛ **استدلال** است. هر نقشه‌ی موضوعی پیامی دارد («فضای سبز در جنوب شهر کم است»، «این مزرعه‌ها خشک‌ترند») و انتخاب‌های کارتوگرافیک، از
طبقه‌بندی تا رنگ، می‌توانند این پیام را روشن، مبهم یا حتی وارونه کنند. کارتوگرافی دانش و هنر طراحی این استدلال است.

## اجزای نقشه و سلسله‌مراتب بصری

یک نقشه‌ی کامل (برای چاپ یا گزارش) این اجزا را دارد:

| جزء | کار |
|---|---|
| **بدنه‌ی نقشه** | خود داده‌ها روی نقشه‌ی پایه |
| **عنوان** | پیام نقشه، نه فقط نام لایه («تراکم مدرسه در محله‌ها»، نه «schools») |
| **راهنما** (legend) | معنای نمادها و رنگ‌ها با واحد |
| **مقیاس** | نوار مقیاس (در نقشه‌ی رقومی بهتر از کسر عددی) |
| **جهت شمال** | به‌ویژه اگر نقشه چرخیده یا مخاطب عام است |
| **منبع و تاریخ** | منبع داده، تاریخ، تهیه‌کننده؛ و ذکر مجوز (OSM، Copernicus) |
| **نقشه‌ی موقعیت** (اختیاری) | جای منطقه در محدوده‌ی بزرگ‌تر |

**سلسله‌مراتب بصری** یعنی مهم‌ترین چیز، بیشترین توجه را بگیرد: لایه‌ی موضوعی پررنگ و پرکنتراست، نقشه‌ی پایه کم‌رنگ و خاکستری، اجزای کمکی کوچک و آرام. اصل **شکل و
زمینه**: موضوع باید از زمینه جدا دیده شود. نقشه‌ی پایه‌ی پررنگ و شلوغ، رایج‌ترین دشمن این اصل است.

## متغیرهای بصری

ژاک برتن، نقشه‌نگار فرانسوی، در ۱۹۶۷ **متغیرهای بصری** را صورت‌بندی کرد: ویژگی‌هایی از نماد که می‌توان برای نمایش داده عوض کرد. هر متغیر برای سطح اندازه‌گیری خاصی (فصل
۲) مناسب است:

| متغیر بصری | اسمی | ترتیبی | کمّی | نمونه |
|---|---|---|---|---|
| **مکان** | ✔ | ✔ | ✔ | جای نماد |
| **اندازه** | | ✔ | ✔ | دایره‌ی متناسب با جمعیت |
| **روشنایی** (value) | | ✔ | ✔ (طبقه‌ای) | طیف روشن به تیره برای تراکم |
| **فام** (hue، رنگ) | ✔ | | | آبی برای آب، سبز برای پارک |
| **شکل** | ✔ | | | مربع برای مدرسه، دایره برای بیمارستان |
| **جهت** | ✔ | | | جهت باد |
| **بافت** | ✔ | ✔ | | هاشور |

دو خطای رایج: نمایش داده‌ی **اسمی با طیف روشنایی** (کاربری‌ها با سبز روشن تا تیره، که ترتیب القا می‌کند) و نمایش داده‌ی **کمّی با فام‌های متفاوت** (جمعیت با رنگین‌کمان،
که ترتیب را نشان نمی‌دهد).

## نقشه‌ی کروپلت و نرمال‌سازی

**نقشه‌ی کروپلت** (choropleth) مناطق را بر اساس مقدارشان رنگ می‌کند و پرکاربردترین نقشه‌ی موضوعی است. قاعده‌ی طلایی آن:

> در نقشه‌ی کروپلت **نسبت یا تراکم** نشان دهید، نه مقدار مطلق.

چرا؟ چون چشم مساحت رنگ را می‌بیند. محله‌ی بزرگ با جمعیت زیاد ممکن است تراکم کمی داشته باشد؛ اگر «جمعیت» را رنگ کنید، محله‌های بزرگ همیشه تیره دیده می‌شوند. برای
مقدار مطلق، **نماد متناسب** (دایره‌ای که مساحتش با مقدار متناسب است) را روی مرکز منطقه بگذارید. تبدیل به نسبت با SQL ساده است:

```{.sql .run}
SELECT name, population,
       round((ST_Area(geom::geography) / 1e6)::numeric, 1)                 AS km2,
       round(population / (ST_Area(geom::geography) / 1e6))               AS people_per_km2
FROM neighborhoods
ORDER BY people_per_km2 DESC;
```

## طبقه‌بندی داده

برای نقشه‌ی کروپلت، مقدارهای پیوسته معمولاً در **۳ تا ۷ طبقه** دسته‌بندی می‌شوند؛ چشم بیش از هفت روشنایی را به‌سختی از هم جدا می‌کند. روش طبقه‌بندی، ظاهر نقشه را
عمیقاً تغییر می‌دهد:

| روش | چگونه | مناسب برای | خطر |
|---|---|---|---|
| **فاصله‌ی برابر** | بازه‌ی کمینه تا بیشینه به طبقه‌های هم‌پهنا | داده‌ی یکنواخت؛ مقایسه‌ی چند نقشه با یک مقیاس | با داده‌ی چوله، بیشتر عارضه‌ها در یک طبقه |
| **چندک** (quantile) | هر طبقه تعداد برابری عارضه | داده‌ی چوله؛ رتبه‌بندی | مقدارهای بسیار نزدیک در طبقه‌های جدا |
| **شکست طبیعی** (Jenks) | کمینه کردن واریانس درون طبقه‌ها | خوشه‌های طبیعی داده | مرزها برای هر داده فرق می‌کند؛ مقایسه سخت |
| **انحراف معیار** | فاصله از میانگین بر حسب انحراف معیار | نمایش بالاتر/پایین‌تر از میانگین (طیف واگرا) | نیاز به توزیع نسبتاً نرمال |
| **دستی** | مرزهای معنادار (۰٫۲، ۰٫۴، … یا آستانه‌ی قانونی) | وقتی مرز معنای بیرونی دارد | ذهنی |

مرزهای دو روش رایج را با SQL برای تعداد دانش‌آموز مدرسه‌ها حساب می‌کنیم:

```{.sql .run}
WITH s AS (SELECT min(students) AS lo, max(students) AS hi FROM schools)
SELECT k AS class,
       round(lo + (hi - lo) * (k - 1) / 5.0) AS equal_from,
       round(lo + (hi - lo) * k / 5.0)       AS equal_to,
       (SELECT round(percentile_cont((k - 1) / 5.0) WITHIN GROUP (ORDER BY students)::numeric) FROM schools) AS quantile_from,
       (SELECT round(percentile_cont(k / 5.0)       WITHIN GROUP (ORDER BY students)::numeric) FROM schools) AS quantile_to,
       (SELECT count(*) FROM schools WHERE width_bucket(students, lo, hi + 1, 5) = k)                       AS equal_count
FROM s, generate_series(1, 5) k;
```

در فاصله‌ی برابر، تعداد مدرسه‌ی هر طبقه متفاوت است (`equal_count`)؛ در چندک، هر طبقه حدود ۳۶ مدرسه دارد ولی پهنای طبقه‌ها برابر نیست. `width_bucket` تابع آماده‌ی
PostgreSQL برای طبقه‌ی فاصله‌ی برابر و `percentile_cont` برای چندک است (فصل ۱۲). استودیوی نقشه‌ی سامانه همین روش‌ها را با پیش‌نمایش زنده دارد (فصل ۴۲).

::: warn
**طبقه‌بندی گمراه‌کننده.** با انتخاب روش و مرز، می‌توان یک داده را «بحرانی» یا «آرام» نشان داد. اگر نقشه‌ای برای تصمیم‌گیری می‌سازید، روش طبقه‌بندی را در راهنما بنویسید،
برای مقایسه‌ی دو سال از **یک مرز ثابت** استفاده کنید، و اگر ممکن است هیستوگرام داده را کنار نقشه بگذارید؛ نمودار هیستوگرام استودیو مرزهای طبقه‌بندی لایه را روی خود
هیستوگرام نشان می‌دهد (فصل ۴۳).
:::

## رنگ

سه نوع **طرح رنگ** برای سه نوع داده:

- **ترتیبی** (sequential): یک فام از روشن به تیره؛ برای مقدار کم به زیاد (تراکم، جمعیت، NDVI). قاعده: **روشن = کم، تیره = زیاد** (روی زمینه‌ی روشن).
- **واگرا** (diverging): دو فام با مرکز خنثی؛ برای مقدارهایی که یک نقطه‌ی میانی معنادار دارند (تغییر مثبت و منفی، بالاتر و پایین‌تر از میانگین، امتیاز z کانون داغ در
  فصل ۲۱).
- **کیفی** (qualitative): فام‌های متمایز با روشنایی مشابه؛ برای دسته‌ها (کاربری، نوع مرکز درمانی، خط مترو). حداکثر هشت تا ده رنگ.

مجموعه‌ی **ColorBrewer** (سینتیا بروئر) مرجع رایج طرح‌های رنگی آزموده‌شده برای نقشه است و در QGIS و بیشتر نرم‌افزارها موجود است.

::: note
**رنگ‌کوری.** حدود ۸ درصد مردان نوعی کوررنگی (بیشتر قرمز-سبز) دارند. طیف قرمز-سبز (رایج برای NDVI) برای آن‌ها مبهم است. برای مخاطب عام، طرح‌هایی مثل زرد-سبز-آبی یا
بنفش-نارنجی را ترجیح دهید، یا به جز رنگ، روشنایی را هم تغییر دهید تا نقشه در چاپ سیاه‌وسفید هم خوانا بماند.
:::

## نماد، برچسب و تعمیم

- **نماد نقطه‌ای:** اندازه‌ی ثابت برای وجود (مدرسه این‌جاست)، اندازه‌ی متناسب برای مقدار (تعداد دانش‌آموز). برای نماد متناسب، **مساحت** (نه قطر) را متناسب با مقدار بگیرید.
- **برچسب:** نام نقطه بالا-راست نماد (در فارسی بالا-چپ هم رایج است)، نام خط در امتداد آن، نام چندضلعی در مرکز (با `ST_PointOnSurface`، فصل ۱۵). برچسب‌ها را کم و خوانا نگه
  دارید؛ هاله‌ی سفید دور متن خوانایی را روی زمینه‌ی شلوغ بیشتر می‌کند.
- **تعمیم** (generalization): در مقیاس کوچک‌تر جزئیات کمتر: ساده‌سازی خط‌ها (فصل ۱۸)، حذف عارضه‌های کوچک، ادغام. کاشی‌های برداری سامانه در هر سطح بزرگ‌نمایی این کار را
  خودکار انجام می‌دهند.

## چک‌لیست نقشه‌ی خوب

::: steps
1. پیام نقشه در یک جمله چیست؟ عنوان همان را می‌گوید؟
2. داده نرمال شده است (نسبت، نه مقدار مطلق در کروپلت)؟
3. متغیر بصری با سطح اندازه‌گیری جور است؟
4. روش و تعداد طبقه آگاهانه انتخاب و در راهنما ذکر شده؟
5. طرح رنگ با نوع داده (ترتیبی، واگرا، کیفی) جور و برای رنگ‌کورها خواناست؟
6. نقشه‌ی پایه آرام است و موضوع را نمی‌پوشاند؟
7. راهنما با واحد، مقیاس، منبع، تاریخ و مجوز هست؟
:::

::: summary
- نقشه استدلال بصری است: عنوان پیام، راهنما با واحد، مقیاس، شمال، منبع و تاریخ.
- متغیرهای بصری برتن: اندازه و روشنایی برای کمّی و ترتیبی؛ فام و شکل برای اسمی.
- کروپلت: نسبت یا تراکم، نه مقدار مطلق؛ برای مقدار مطلق نماد متناسب.
- طبقه‌بندی: فاصله‌ی برابر، چندک، شکست طبیعی، انحراف معیار، دستی؛ ۳ تا ۷ طبقه؛ مرزها با `width_bucket` و `percentile_cont`.
- رنگ: ترتیبی (روشن=کم)، واگرا (مرکز معنادار)، کیفی (دسته‌ها)؛ رنگ‌کوری را در نظر بگیرید.
:::

::: teach
**زمان پیشنهادی:** دو جلسه. یک داده را با چهار روش طبقه‌بندی روی چهار نقشه کنار هم نشان دهید و بپرسید «کدام درست است؟»؛ بحث درباره‌ی اینکه «همه درست‌اند ولی پیام
متفاوتی می‌دهند» مهم‌ترین درس کارتوگرافی است. کتاب «چگونه با نقشه دروغ بگوییم» مونمونیر خواندنی تکمیلی خوبی است.
:::
