---
title: پیوست الف ـ واژه‌نامه
---

واژه‌های کلیدی کتاب به ترتیب الفبای فارسی، با معادل انگلیسی و فصلی که مفصل‌تر در آن آمده است.

::: gloss
**SAR** [Synthetic Aperture Radar]{.en}
:   رادار روزنه‌ی مصنوعی (فصل ۴۰).

**SRID** [Spatial Reference ID]{.en}
:   شناسه‌ی سیستم مختصات؛ کد EPSG (فصل ۳).

**UTM** [Universal Transverse Mercator]{.en}
:   سیستم تصویر ناحیه‌ای متری؛ ایران ناحیه‌های ۳۸ تا ۴۱ (فصل ۳).

**WKT / WKB** [Well-Known Text / Binary]{.en}
:   قالب متنی و دودویی استاندارد هندسه (فصل ۱۵).

**آمار ناحیه‌ای** [Zonal statistics]{.en}
:   آمار پیکسل‌های رستر داخل هر چندضلعی (فصل‌های ۲۳ و ۳۶).

**ارجاع خطی** [Linear referencing]{.en}
:   بیان مکان با فاصله در امتداد خط (فصل ۱۸).

**اعتبار هندسه** [Geometry validity]{.en}
:   رعایت قواعد OGC در هندسه؛ شرط تحلیل درست (فصل ۲۲).

**افزونه** [Extension]{.en}
:   بسته‌ی گسترش PostgreSQL مثل PostGIS و pgRouting (فصل ۴).

**امضای طیفی** [Spectral signature]{.en}
:   نمودار بازتاب یک ماده در طول موج‌ها (فصل ۳۱).

**بازتاب طیفی** [Reflectance]{.en}
:   کسر انرژی بازتاب‌شده در یک طول موج؛ ۰ تا ۱ (فصل ۳۱).

**بازنمونه‌گیری** [Resampling]{.en}
:   تعیین مقدار پیکسل‌ها هنگام تغییر شبکه‌ی رستر (فصل ۳۳).

**باند** [Band]{.en}
:   یک لایه‌ی طیفی یا داده‌ای در رستر (فصل ۲).

**برنامه‌ی اجرا** [Query plan]{.en}
:   روشی که پایگاه داده برای اجرای پرسش برمی‌گزیند؛ با EXPLAIN (فصل ۲۰).

**بیضوی** [Ellipsoid]{.en}
:   مدل ریاضی شکل زمین (فصل ۳).

**تراکنش** [Transaction]{.en}
:   مجموعه دستور همه‌یاهیچ؛ ACID (فصل ۱۴).

**ترکیب بی‌ابر** [Cloud-free composite]{.en}
:   میانه‌ی پیکسل‌های بی‌ابر چند تصویر (فصل ۳۳).

**تصحیح اتمسفری** [Atmospheric correction]{.en}
:   حذف اثر جو؛ از بازتاب بالای جو به سطح (فصل ۳۳).

**تصویر نقشه** [Map projection]{.en}
:   قاعده‌ی بردن سطح خمیده به صفحه (فصل ۳).

**تفکیک** [Resolution]{.en}
:   مکانی، طیفی، زمانی و رادیومتری (فصل ۳۲).

**توپولوژی** [Topology]{.en}
:   قواعد رابطه‌ی عارضه‌ها: همسایگی، اتصال (فصل‌های ۲ و ۲۲).

**حریم** [Buffer]{.en}
:   ناحیه‌ی تا فاصله‌ی معین از هندسه (فصل ۱۸).

**حوزه‌ی دسترسی** [Isochrone / Service area]{.en}
:   جاهای قابل رسیدن در زمان یا فاصله‌ی معین روی شبکه (فصل ۲۴).

**خودهمبستگی فضایی** [Spatial autocorrelation]{.en}
:   شباهت مقادیر نزدیک به هم؛ شاخص موران (فصل ۲۱).

**داده‌نما** [Datum]{.en}
:   جایگاه بیضوی نسبت به زمین؛ WGS84، ED50 (فصل ۳).

**درخت R** [R-tree]{.en}
:   ساختار شاخص مکانی از مستطیل‌های تودرتو (فصل ۲۰).

**رستر** [Raster]{.en}
:   شبکه‌ی منظم پیکسل‌ها (فصل ۲).

**سری زمانی** [Time series]{.en}
:   مقادیر یک کمیت در تاریخ‌های پیاپی (فصل ۳۷).

**سطح پردازش** [Processing level]{.en}
:   L1C بازتاب بالای جو، L2A بازتاب سطح (فصل ۳۳).

**شاخص** [Index]{.en}
:   ساختار کمکی برای سرعت پرسش؛ در PostGIS از نوع GiST (فصل ۲۰).

**شاخص طیفی** [Spectral index]{.en}
:   ترکیب ریاضی باندها؛ NDVI، NDWI، … (فصل ۳۵).

**طبقه‌بندی نظارت‌شده** [Supervised classification]{.en}
:   طبقه‌بندی با نمونه‌ی آموزشی (فصل ۳۹).

**عارضه** [Feature]{.en}
:   یک پدیده با هندسه و ویژگی؛ یک سطر جدول (فصل ۲).

**فراداده** [Metadata]{.en}
:   داده درباره‌ی داده (فصل ۲).

**فنولوژی** [Phenology]{.en}
:   چرخه‌ی زندگی گیاه در طول فصل (فصل ۳۷).

**قید** [Constraint]{.en}
:   قاعده‌ای که پایگاه داده همیشه اعمال می‌کند (فصل ۱۴).

**لایه** [Layer]{.en}
:   مجموعه‌ی عارضه‌های یک نوع؛ در پایگاه داده یک جدول (فصل ۱).

**ماتریس خطا** [Confusion matrix]{.en}
:   مقایسه‌ی کلاس واقعی و پیش‌بینی‌شده (فصل ۳۹).

**مدل رقومی ارتفاع** [DEM / DSM / DTM]{.en}
:   رستر ارتفاع؛ سطح یا زمین (فصل ۳۸).

**منحنی میزان** [Contour]{.en}
:   خط هم‌ارتفاع (فصل‌های ۳۸ و ۴۹).

**نرمال‌سازی** [Normalization]{.en}
:   طراحی جدول‌ها به‌گونه‌ای که هر واقعیت یک جا ذخیره شود (فصل ۱۰).

**نزدیک‌ترین همسایه** [k-Nearest Neighbors (KNN)]{.en}
:   یافتن نزدیک‌ترین عارضه‌ها با <-> (فصل ۱۹).

**نما** [View]{.en}
:   پرسش ذخیره‌شده‌ای که مثل جدول خوانده می‌شود (فصل ۱۴).

**هندسه** [Geometry]{.en}
:   شکل و مکان عارضه؛ نوع داده‌ی PostGIS (فصل‌های ۲ و ۱۵).

**ورونوی (تیسن)** [Voronoi (Thiessen)]{.en}
:   تقسیم فضا به نزدیک‌ترین نقطه (فصل ۱۸).

**پراکنش دوگانه** [Double bounce]{.en}
:   بازتاب دوباره‌ی موج رادار بین دیوار و زمین؛ شهر روشن (فصل ۴۰).

**پوسته‌ی محدب** [Convex hull]{.en}
:   کوچک‌ترین چندضلعی محدب دربرگیرنده (فصل ۱۸).

**پیوند مکانی** [Spatial join]{.en}
:   پیوند دو جدول با شرط مکانی (فصل‌های ۱۳ و ۱۷).

**پیکسل مختلط** [Mixed pixel]{.en}
:   پیکسلی که بازتاب چند پوشش را با هم دارد (فصل ۳۲).

**ژئوئید** [Geoid]{.en}
:   سطح هم‌پتانسیل گرانش؛ مرجع ارتفاع از سطح دریا (فصل ۳).

**کاشی برداری** [Vector tile (MVT)]{.en}
:   داده‌ی برداری برش‌خورده برای نقشه‌ی وب سریع (فصل ۴۵).

**کانون داغ** [Hot spot]{.en}
:   خوشه‌ی معنادار مقادیر بالا؛ آماره‌ی Gi* (فصل ۲۱).

**کلید اصلی** [Primary key]{.en}
:   ستون یکتاکننده‌ی هر سطر (فصل ۱۰).

**کلید خارجی** [Foreign key]{.en}
:   ستون اشاره‌گر به کلید اصلی جدول دیگر (فصل‌های ۱۰ و ۱۴).

**گراف** [Graph]{.en}
:   مدل شبکه از گره‌ها و یال‌ها (فصل ۲۴).

**گزاره‌ی مکانی** [Spatial predicate]{.en}
:   تابع درست/نادرست بین دو هندسه (فصل ۱۷).

**گسیلمندی** [Emissivity]{.en}
:   کارایی گسیل حرارتی نسبت به جسم سیاه (فصل ۴۰).

:::
